## 🐱 Featured: DevMem

<p align="center">
  <a href="https://github.com/kizzis/devmem">
    <img src="./assets/devmem-cat.gif" alt="DevMem tray cat: green, orange and red cats running faster as memory gets tighter" width="432" />
  </a>
</p>
<p align="center"><sub>🟢 여유 · 🟡 주의 · 🔴 위험. 메모리가 부족할수록 고양이가 빨리 달립니다.</sub></p>

IDE, 브라우저, WSL/Docker, Gradle, Node dev server를 한꺼번에 띄우면 PC가 느려집니다.<br />
**DevMem**은 트레이에 사는 작은 고양이로 메모리가 얼마나 부족한지 보여 주고, 무엇이 메모리를 먹는지 개발 단위로 묶어 알려 주고, 안 쓰는 것만 골라 정리합니다.

- 메모리 사용량 약 15MB, 실행 파일 약 4MB
- 사용 중인 프로그램은 지키고, 정리는 확인 창을 거친 뒤에만
- 1시간 넘게 안 본 브라우저 탭 잠재우기, 누수 의심 프로세스 감지
