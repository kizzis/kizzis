**Full-Stack Developer · AI Product Builder**

Spring 백엔드로 커리어를 시작해 지금은 **생성형 AI 엔진을 활용한 서비스를 개발하고 운영하고 있습니다.** 기획부터 배포까지 end-to-end로 맡고, 설계·구현·검수 전 과정에 Claude Code와 Codex를 결합해 혼자서도 팀 단위의 산출물을 내는 개발 방식을 실무에서 운영 중입니다.

- 🎓 **AI 교수 시스템** — LLM 기반 교육 플랫폼의 백엔드·관리자·프론트·시스템 연동을 설계하고 구축
- 🧠 **Vibe Coding** — Claude Code · Codex를 개발 프로세스의 일부로 두고, 설계 문서 → 프로토타입 → 리뷰 루프를 AI와 반복
- 🐱 **DevMem** (side) — Rust로 만든 Windows 트레이 앱. 메모리 압박을 고양이 애니메이션으로 알리고, 사용 중인 프로세스는 지키면서 유휴 프로세스만 정리. 상주 메모리 약 15MB

관심사: AI 에이전트 워크플로우, 개발 생산성 도구, 시스템 프로그래밍
